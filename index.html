NYC TLC High-Volume Mobility Lakehouse & Analytics Marts

Designed and engineered an automated, batch-driven Medallion Lakehouse pipeline processing 35M+ trip records. Built a deterministic PySpark data validation framework separating dirty data into dedicated quarantine partitions, enriched clean data with taxi zone dimension lookups, and generated aggregated analytical data marts for Amazon Athena SQL querying.

Bronze Tier
Raw Ingestion
  • 90M–120M multi-month Parquet records.
  • Raw taxi zone lookup dimension CSVs.
  • Streaming multipart HTTP uploads into S3.
  • ingestion.done marker file synchronization.
Silver Tier
Curated & Quarantine
  • Filtered Lyft dataset (35M+ trips).
  • 10 Data Quality rules tagging corrupt rows.
  • Quarantined records isolated to rejected/.
  • Broadcast joins with Zone lookup dimensions.
  • Partitioned by pickup_date in Parquet.
Gold Tier
Analytical Marts
  • Daily Borough Summary: Revenue & miles.
  • Hourly Pattern Summary: Peak demand & tip %.
  • Route Matrix: High-traffic OD zone pairs.
  • Athena-ready for sub-second SQL queries.

Tag-and-Quarantine Cleanse

Single DAG pass tagging 10 failure conditions (zero miles, fare spikes, timestamp inversions); writes clean rows to Curated and bad rows to S3 quarantine.

Shuffle Elimination

Utilized Spark broadcast() joins for dimension tables (~265 rows), eliminating expensive network shuffling across cluster nodes.

End-to-End Observability

Integrated DynamoDB audit logging recording records_read, records_written, records_rejected, and runtime durations for every stage.
